# 🏢 Projeto: Ferramenta de Simulação para Controle de Investimentos em Fundos Imobiliários (FIIs) 📊

## 🎯 Objetivo

Desenvolver uma ferramenta no Microsoft Excel para simular a evolução de investimentos em Fundos de Investimento Imobiliário (FIIs), permitindo visualizar o crescimento do patrimônio e estimar dividendos ao longo do tempo.

💰 A planilha demonstra como os aportes mensais e os rendimentos hipotéticos podem influenciar os resultados em diferentes períodos.

## 🛠️ Ferramentas Utilizadas

- 📗 Microsoft Excel
- 🧮 Fórmulas financeiras
- 📈 Juros compostos
- 📊 Gráficos para visualização e comparação de cenários
- 🔎 Análise e organização de dados

## ⚙️ O Que Foi Desenvolvido

A planilha permite comparar a evolução do patrimônio em diferentes períodos, considerando uma taxa de rendimento mensal hipotética. Os resultados são apresentados em tabelas e gráficos para facilitar a compreensão do crescimento patrimonial e a comparação entre os cenários simulados.

### 📌 Funcionalidades Desenvolvidas

- 💵 **Cálculo do patrimônio futuro:** utilização da função VF (Valor Futuro) do Excel.
- 📅 **Simulação de cenários:** projeções para períodos de 2, 5, 10, 20 e 30 anos.
- 🏦 **Estimativa de dividendos:** cálculos baseados nas premissas definidas na planilha.
- 🏷️ **Intervalos nomeados:** organização e identificação dos dados utilizados nos cálculos.
- 👤 **Perfil de investidor:** distribuição do aporte mensal utilizando a função PROCV e uma tabela de apoio.
- 📊 **Visualização de dados:** criação de tabelas e gráficos para comparar os cenários e facilitar a interpretação dos resultados.

## 🧠 Aprendizados

O desenvolvimento deste projeto proporcionou a prática de diferentes recursos do Excel, incluindo:

- 🧮 Aplicação de fórmulas financeiras.
- 📋 Organização e estruturação de dados.
- 📈 Construção de gráficos para visualização de resultados.
- 🔍 Comparação e interpretação de cenários.
- 💡 Transformação de cálculos em informações visuais para facilitar a análise.

## ⚠️ Observação

As taxas e os resultados apresentados são hipotéticos e têm finalidade exclusivamente educacional. As simulações não representam previsões de rentabilidade nem garantias de retorno de investimentos em FIIs.
